## 2. TP規格コンテナの体系とモジュール仕様

### 2.1 TP規格とは
自動車産業・製造業物流において標準化されたプラスチックコンテナ規格（Toyota Plastic Box / JIS準拠）です。
**基準モジュール寸法（間口 335 mm × 奥行 335 mm）** を単位とし、倍数・分数関係にある異なる型番同士でも**底面のTP格子リブ構造により相互嵌合（スタッキング）が可能**です。

### 2.2 TP規格の平面モジュール関係

```
 ┌───────────────┬───────────────┐
 │   TP-330系    │   TP-330系    │
 │ (335 x 335)   │ (335 x 335)   │  ──► 合計: 670 x 335 mm (TP-360系と完全一致)
 ├───────────────┴───────────────┤
 │           TP-360系            │
 │         (670 x 335)           │
 └───────────────────────────────┘

 ┌───────────────────────────────┐
 │           TP-360系            │
 │         (670 x 335)           │
 ├───────────────────────────────┤  ──► 合計: 670 x 503 mm (TP-460系と完全一致)
 │   TP-330系    │   TP-330系    │
 │ (335 x 335)   │ (335 x 335)   │
 └───────────────┴───────────────┘
```

### 2.3 高さ体系と嵌合深さ (fitting_depth)

TP規格の高さは規格化されており、異なる高さの箱を組み合わせても段積み全体の高さを揃えやすくなっています。

- **代表的外寸高さ**:
  - **1型 (浅型)**: 103 mm
  - **1.5型 (中浅型)**: 149 mm
  - **2型 (標準型)**: 195 mm
  - **3型 (深型)**: 288 mm
- **嵌合深さ (`fitting_depth`)**:
  - TP-110 / 130系: **8.0 mm**
  - TP-330 / 340 / 360 / 460 / 480 / 490系: **10.0 mm**
- **段積み総高さの計算式**:
  $$H_{total}(N) = H_{bottom} + \sum_{k=2}^N (H_k - fitting\_depth_k)$$

### 2.4 側面リブ厚み (`rib_thickness`) の定義と計算

コンテナの「側面リブ厚み」は、樹脂単板の板厚ではなく、**外周フランジ・補強リブ構造を含めた片側側壁の総厚み**として定義されます。

$$\text{側面厚み} = \frac{\text{外寸} - \text{有効内寸}}{2} \quad (\text{または} \quad \frac{\text{外寸} - \text{内寸}}{2})$$

- **TP規格箱**:
  - 外寸 335mm に対し内寸 300mm / 有効内寸 291mm $\implies$ 片側側面厚み **約 17.5mm 〜 22.5mm**（代表値 **22.0mm**）
  - 全てのTPシリーズで側壁リブ・フランジ厚みがほぼ共通規格（22.0〜22.5mm）となっています。

## 4. パレット (1200x1000) への適合性考察

1. **TP-340系 (503 × 335 mm)**:
   - 長辺 1200mm に対して $503 \times 2 = 1006\text{ mm}$、または $335 \times 3 = 1005\text{ mm}$、$335 \times 4 = 1340\text{ mm}$（1360mm未満許容枠内！）。
   - 短辺 1000mm に対して $335 \times 3 = 1005\text{ mm}$（※5mmオーバーハングは短辺禁止のためNGだが、$503 \times 2 = 1006\text{ mm}$ も同様。したがって $335 \times 2 + 503 \text{の組み合わせ}$ や長短混在パターンで $1000\text{mm}$ 以下に収める設計が可能）。
2. **TP-360系 (670 × 335 mm) & TP-460系 (670 × 503 mm)**:
   - 長辺 1200mm に対して $670 \times 2 = 1340\text{ mm}$（**長辺1360mm未満の許容枠を最大限に活かしたジャストフィット配置**が可能！）。
   - 短辺 1000mm に対して $503 \times 2 = 1006\text{ mm}$（$503 + 335 = 838\text{ mm}$ であれば 800〜1000mm の制約に完璧に合致）。
3. **OC-50L (530 × 366 mm)**:
   - 長辺 1200mm に対して $530 \times 2 = 1060\text{ mm}$、短辺 1000mm に対して $366 \times 2 = 732\text{ mm}$（800mm未満のため単独列は工夫が必要）または $530 + 366 = 896\text{ mm}$（800〜1000mmに適合）。
