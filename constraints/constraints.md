本ドキュメントは、パレタイズアルゴリズムの実装 (`algorithm-programmer`) および制約検証 (`supervisor`) における荷姿・積載の共通制約を定義する。

---

## 1. パレットおよび積載領域仕様

| 項目 | 制約値 / 仕様 | 備考 |
| :--- | :--- | :--- |
| **パレット種別** | 標準樹脂パレット | 重量パラメータは考慮不要 |
| **パレット寸法 (L × W × H)** | **スキッドが参照するパレットDBの寸法** | length=X、width=Y、height=本体高。Lを長辺、Wを短辺とする |
| **荷姿センタリング** | 荷姿外形の中心をパレット中心に一致 | X/Y各方向の中心座標誤差 0.01 mm以内 |
| **最大積載高さ (max_height)** | **スキッド設定値以下** | パレット上面からの荷物部分の高さ。本体高を差し引かない |
| **荷山最大L (max_x_span)** | **スキッド設定値以下** | 全段・箱と蓋を含むX方向外接幅。固定下限なし |
| **荷山最大W (max_y_span)** | **スキッド設定値以下** | 全段・箱と蓋を含むY方向外接幅。固定下限なし |
| **箱間クリアランス** | **0 mm** | 箱同士は密着させて配置 |
| **パレット端はみ出し** | **確認情報のみ、寸法制約にはしない** | 箱・蓋外形による左右・手前・奥の量を表示。底面支持率は別途必須 |

6つの設定値は0より大きい有限数値とし、荷山最大Lは最大W以上とする。
パレット本体Hは3D表示と総高さの算出に使う。総高さ＝本体H＋実際の荷山高さ。
品番方式のケースは `skid_id` から使用パレットと荷山上限を解決し、本体寸法はパレットDBを参照する。
ケースにはこれらを重複保存しない。未登録のパレット・荷山上限は初期値で補わず、
新規ケース作成・計算を停止する。明示された不正値もエラーとする。
コアモデル単体の初期値（本体1200 × 1000 × 130 mm、荷山上限1360 × 1100 × 1200 mm）は、
現行カタログの未登録設定を補う値ではない。

### 配置結果の座標基準

- 結果JSONは `schema_version: 2`、`input_mode: "part_number"`、
  `coordinate_reference: "combined_footprint_min_xy_top_z"` を持つ。
- `position.x/y` は、回転後の箱本体と蓋を合わせた外接形状の最小X・最小Y角。蓋と箱はXY中心を合わせる。
- `position.z` は蓋を含む配置物の上面高さ。蓋がない場合は箱上面高さ。
- `dimensions.width/length` は回転後の箱本体寸法、`dimensions.height` は蓋厚を含む高さ。
  蓋のXY寸法は `lid_dimensions` に記録する。
- 旧形式の結果の読み込み・表示は廃止した。現行の品番ケースから再計算する。

## 2. 箱の配置・回転制約

1. **天地（上下）固定**
   - 箱の上下反転、横倒し配置は禁止。常に上面が上を向くように配置する。
2. **回転角度**
   - 水平方向（Z軸回り）の回転は **0度** または **90度** のみ許可。
3. **ケース別の最大外形とパレット端はみ出し（2026-11-03改訂）**
   - 荷山外接寸法L/W/Hは各ケースが参照するスキッドの最大設定値以下とする。境界値は許可する。
     固定800 mm下限は廃止し、代わりの下限は設けない。最大外形は目標寸法ではない。
   - はみ出し許容値と単載670 mm以上の辺に対する例外は廃止する。
     パレット中心合わせ後の箱・蓋外形から、左・右・手前・奥のはみ出し量を求める。
     はみ出しがある場合は「要確認」として表示するが、それだけではNGにしない。
   - 最下段箱の本体底面とパレット矩形との交差面積を用い、底面支持率85%以上を必須とする。
     はみ出し警告も支持率も、実物の転倒・安定性を保証しない。
   - 旧 `min_x_span` / `min_y_span` / `max_overhang_x_mm` / `max_overhang_y_mm` /
     `max_small_edge_overhang_mm` は現行のケース・スキッド設定に使用しない。
     旧設定の読み込み・変換・本体Hの補完は現行の運用手順ではない。
     結果の `input_box_variants` は投入記録として維持するが、例外判定には使わない。
   - 旧結果は新仕様に適合するとは限らない。再計算・独立検証を行う。
4. **単載の下段同一配置・安定した端数最上段（2026-11-05改訂）**
   - 同一箱型番・同一蓋の単載では、制約を満たす生成候補の中から、荷山全体の配置個数が最大の案を選ぶ。
     同数なら最高層の外周4隅支持ありを例外配置より優先し、次に低い荷姿高さ、
     端数段なし（各段の箱数が同数）、高い外形占有率、X方向が荷山長手となる案、中央接触ありの順に比較する。
     中央接触の優先は最後の同点解消であり、5点指定以外の必須条件ではない。完全同点なら既存の候補順を維持する。
     外形占有率は、箱・蓋を含む荷姿外接矩形の面積をケースの最大L×最大Wで割った値とし、
     ロの字の中央空間も含む。体積充填率や実物の安定性とは異なる指標である。
   - 格子状・分割配置に加え、長方形4箱で中央を空けた定形の風車配置を最大1候補比較する。
     5箱以上の投入では、3×3の範囲の外周4隅と中央へ各1箱を置く定形5点配置も比較する。
     それ以外に箱を離して外接面積だけを増やす処理や、風車を複数組並べる探索は行わない。
     投入数に応じて1段の個数を減らす候補も比較するが、任意の配置に対する大域最適性は保証しない。
   - 選定した1段分のパターンを、
     完全な下段では同じX/Y位置・回転角度・箱数で繰り返す。段ごとの配置反転は行わない。
     分割配置の短い箱列・箱行は、そのブロックをY方向・X方向の中央へ寄せる。
   - Z座標は箱・蓋の高さと嵌合深さから算出する。積み順番号は全段を通じた連番とする。
   - 最上段だけ、下段パターンの部分集合による端数配置を許可する。
     支持条件・底面支持率・嵌合・高さ等を全て満たす部分集合を探し、残数を配置できなければ
     より少ない部分集合も比較する。支持不可の箱は未配置として明示する。
     積み上げ途中の下段は再配置せず、最上段の箱を浮かせたりコラム条件を免除したりしない。
     最下段だけの少数投入も、実際に配置した箱の寸法・支持条件を検証する。
   - 混載には、下段同一配置の要件を適用しない。候補評価でも4隅支持を優先し、
     短いブロックの中央寄せは同じコラム全段を移動して他の制約を再確認する。

## 3. 嵌合（かんごう）・段積みルール

空箱の上下段積みおよび混載時の嵌合ルールは以下の通りとする。

### (1) TP規格箱の段積み・嵌合

- **モジュール嵌合**:
  - TP規格箱は底面リブ・フチ形状がモジュール化されており、同一型番はもちろん、
    モジュール倍数関係にある箱（例: TP-330系 2個の上に TP-460系 1個、またはその逆など）の嵌合段積みが可能。
  - TP規格箱同士の組み合わせ段積みルールに準拠すること。
- **外嵌め蓋付きTP箱**:
  - 選択した蓋の `fit_type` が `外嵌め` のTP箱は、積み方の判定上、非TP箱と同じコラム積み限定として扱う。箱DB上の規格種別は変更しない。
  - 上下段は同一の蓋IDを使用し、箱・蓋を含む外形矩形のX/Y位置および範囲を一致させる。箱IDは異なってもよい（例: 同じ外嵌め蓋を使うTP-331とTP-332）。
  - TPモジュール嵌合による異なる外形・位置の段積み、および外嵌め蓋付きTP箱とそれ以外の箱との段積みは禁止する。
- **嵌合高さの計算**:
  - `fitting_depth` は、積み重ねる上段箱（これから配置する箱）の値を使う。
  - 上段箱の底面Z座標 = `下段箱の上面Z座標 - 上段箱のfitting_depth`

### (2) 非TP規格箱（その他箱）の段積み

- **コラム積み（同一フットプリント）限定**:
  - 非TP規格箱は、同じ共通箱モデルの箱同士のみ直上に積み重ね可能。品番や現場の箱名称が違っても、共通モデルが同じならこの条件を満たす。
  - 箱・蓋を含む外形矩形のX/Y位置および範囲を一致させ、単一の箱で支持する。寸法が同じでも、共通モデルが異なる箱の段積みは許可しない。

### (3) 支持・安定性制約

- **空中配置の禁止**:
  - すべての箱は、底面が「パレット上面」または「適切な下段の箱の上面」によって確実に支持されていなければならない。
- **リブ干渉の回避**:
  - リブ厚み（`rib_thickness`）による干渉・浮き上がりが生じない配置とすること。
- **下段支持箱のサイズ制限**:
  - 上段箱を直接支持する下段箱について、上段箱より幅・奥行きの両方がそれぞれ 1.0 mm を超えて大きい場合、その段積みは禁止する。
  - 幅・奥行きの一方のみが 1.0 mm を超えて大きい場合、または両方とも同等（差が 1.0 mm 以内）の場合は許可する。

### (4) 下段隅の被覆条件（2026-10-27追加）

- **合格条件**: 各上段箱の本体底面が覆う、直接支持する下段箱群の隅が、
  同じXY位置を重複除外して **2か所以上** であること。
  各下段箱に2隅を要求するものではなく、隣接する隅である必要もない。
- **適用対象と例外**:
  - パレット直置きは対象外。単載・混載、蓋の有無によらず適用する。
  - 外嵌め蓋付きTP箱は、既存の「同じ蓋ID・箱蓋外形の位置と範囲一致・単一支持」の
    コラム積み条件を満たす場合に限り、本条件を免除する。箱型番は異なってもよい。
  - 非TP箱は、既存の「同じ箱型番・箱蓋外形の位置と範囲一致・単一支持」の
    コラム積み条件を満たす場合に限り、本条件を免除する。蓋ID自体の一致は要求しない。
  - 型番・規格・蓋種別だけで自動的に免除してはならない。コラム積み違反は引き続きNG。
- **直接支持箱**: 既存の支持面判定と同じ高さ・平面重なり条件で抽出する。
  別の高さの箱や、点・辺だけで接する箱は含めない。
  支持高さの判定には上段箱の嵌合深さを使い、既存の許容差は変更しない。
- **下段の隅**: 各直接支持箱の回転後の箱・蓋を合わせた外形矩形の4頂点を使う。
  支持箱群全体の外接矩形の4頂点に置き換えない。
- **上段の被覆範囲**: 箱本体底面の矩形を使い、上段の蓋の張り出しを含めない。
  辺・頂点上も含め、X/Y各方向に0.01 mm以内の許容差を認める。
  結果JSONは座標基準に従って箱本体底面座標に正規化して判定する。
- **重複除外**: X差・Y差がそれぞれ0.01 mm以内の隅は同じ位置として数える（境界値を含む）。
  入力順に依存しないようXY辞書順に整列し、採用済み代表点のいずれとも同一位置でない点を採用する。
  近接点の連鎖で許容差を超えて離れた点までまとめない。
  浮動小数点演算の境界誤差だけを吸収するため、比較には追加で1e-9 mmの数値誤差を許容する。
- **既存制約の維持**: 支持率85%以上、嵌合・コラム積み、下段支持箱サイズ制限、積み順等は引き続き適用する。
  最高層四隅高さ一致とは別の条件であり、本条件に合格・免除でも他の制約は免除しない。
- **適用の限界**: 中央部分のみへの配置等を除外する幾何学的な近似条件である。
  リブ・フチの実接触、蓋の耐荷重、実物の嵌合・安定性を保証しない。
  支持位置の間隔・偏り・重心による追加制限は今回導入しない。

## 4. 積載順序（積み込み手順）の制約

- **下段優先・物理的整合性**:
  - 積み込み順序 `order`（1, 2, 3, ...）は、実際にロボットや作業者が配置可能な順序であること。
  - 原則として下段の箱が配置された後に、その上段の箱が配置されること。
  - 後から配置する箱が、既に配置された箱と空間的に干渉・衝突しない順序であること。

## 5. 上載せ平パレットの支持安定性（2026-11-05改訂）

- **判定対象**: 下側と同じ寸法・同じXY位置の平パレットを荷山上面に載せる。
  均等荷重を仮定し、荷重重心はパレット中心とする。従来の「四隅の存在は絶対必須」を置き換える。
- **接触支持部**: パレット下面と平面上で正の面積を共有する箱・蓋の露出上面だけを使う。
  この範囲の最高上面から3.0 mm以内（境界を含む）の支持箱だけを同高として扱う。
  上段箱に覆われた部分、低い箱、パレット外の張り出し部分は接触支持領域に加算しない。
  高い箱が先に接触して必要支持位置が届かない場合はNG。下段の低い箱が存在するだけではNGにしない。
- **原則4点支持**: 全段・箱と蓋を含む荷山外接矩形の4頂点を覆う同高の露出上面があり、
  それぞれの支持面が上載せパレット下面とも接触すること。
  外接頂点がパレット外にある場合も、隅を覆う支持面のパレット内接触部分を用いて安定性を確認する。
  パレット自身の4頂点直下に箱があることや、中央・内部空間の充填は要求しない。
- **箱種別の5点支持**: 箱DBの任意項目 `top_support_points` で4または5を指定できる。
  未指定時は `TP331` / `TP-331` が5、それ以外が4。不正値は明示的なエラーとする。
  実際の接触支持箱に5点指定が1箱でも含まれれば、パレット中心にも同高の接触支持領域が必要。
  点数は必要な位置の数であり、箱の個数ではない。1箱が複数位置を支持してもよい。
- **1箱による複数隅支持**: 四隅支持が成立していても、1箱の露出接触面が荷山外接矩形の2隅以上を覆う場合、
  パレット内の接触支持領域全体の外接矩形の短辺を670 mm以上とする（境界を含む）。
  箱単体の短辺や辺上の連続長ではない。別々の4箱で各隅を覆う場合には、この短辺条件は要求しない。
- **670 mm例外（長辺・短辺の両側）**: 別々の箱で四隅を支持する場合は670 mm条件を要求しない。
  4隅が欠ける場合だけ、同高の接触支持領域の外接矩形の前/奥の両辺にX方向で各670 mm以上、
  かつ左/右の両辺にY方向で各670 mm以上の連続支持を要求する。短辺側も含む4辺すべてが必要。
  受け側の位置は全段荷山外形・パレット端ではなく、最上面の実接触支持領域の外周である。
  途中に長い支持線があっても外周の短い辺の代わりにはしない。
  各辺に沿った直線上で同高の複数箱が隙間なく連続すれば合算する（境界670 mmを含む）。
  隙間をまたいだ合計・外接幅やパレット外の辺長は加算しない。5点指定の中央接触は免除しない。
- **偏り・転倒の判定**: 実際の接触支持領域の頂点から凸包（支持多角形）を求め、
  パレット中心がその厳密な内部にあることを必須とする。外側・辺上はNG。
  凸包の面積重心とパレット中心のずれは、X方向で `max_x_span / 4` 未満、
  Y方向で `max_y_span / 4` 未満とする（1/4ちょうどもNG）。
  基準矩形はパレット中心に配置した設定上限 `max_x_span × max_y_span` であり、
  実際の荷山外形やパレット本体寸法を分母にしない。
- **支持の広がり**: 支持凸包の面積が設定上限面積 `max_x_span × max_y_span` の65%以上であること
  （65%ちょうどを含む）。内部空間は凸包面積に含め、実接触面積率とは区別する。
  偏り・面積条件は四隅支持・670 mm例外・5点支持のすべてに適用する。
- **混載上段の四隅直上候補**: 既存の行詰め・風車等の候補を残し、下段四隅の箱と同じ外形・位置の
  直上候補、およびその残箱充填候補を別枠で追加する。数量・回転・嵌合・底面支持率等を免除しない。
  四隅への配置を強制せず、中央支持が必要な場合も既存の条件で比較・検証する。
- **他の制約**: 荷山外形のセンタリング、箱の底面支持率85%、嵌合・積み順等は維持する。
- **適用の限界**: 剛体・静的均等荷重の幾何近似であり、実際のリブ接触、耐荷重、たわみ、
  衝撃・搬送時の安全性は保証しない。3 mm差の許容は運用上の同高近似であり厳密な同時接触保証ではない。

## 6. 制約検証（Supervisorチェック項目）一覧

`supervisor` はアルゴリズムの出力結果（`palletize_result`）に対して以下の項目を検証する：

| チェック項目 | 合格基準 (PASS) | NG時の対応 |
| :--- | :--- | :--- |
| **積載高さ** | 全ての箱の最高Z座標がケースのmax_height以下 | 超過箱の除外または段数削減 |
| **長辺寸法** | 荷姿全体のX方向幅がケースのmax_x_span以下。固定下限なし | 超過の是正 |
| **短辺寸法** | 荷姿全体のY方向幅がケースのmax_y_span以下。固定下限なし | 超過の是正 |
| **方向別はみ出し（確認情報）** | 合否に含めず、左右・手前・奥の量と要確認警告を表示 | 実際の運用で許容できるか確認 |
| **荷姿センタリング** | 箱・蓋外形から求めた荷姿外接矩形の中心がパレット中心と各方向0.01 mm以内で一致 | 配置全体を再センタリングし、支持率を再確認 |
