# 荷姿制約定義書 (constraints.md)

本ドキュメントは、パレタイズアルゴリズムの実装 (`algorithm-programmer`) および制約検証 (`supervisor`) における荷姿・積載の共通制約を定義する。

---

## 1. パレットおよび積載領域仕様

| 項目 | 制約値 / 仕様 | 備考 |
| :--- | :--- | :--- |
| **パレット種別** | 標準樹脂パレット | 重量パラメータは考慮不要 |
| **パレット寸法 (W × L)** | **1200 mm × 1000 mm** | 長辺: 1200 mm, 短辺: 1000 mm |
| **荷姿センタリング** | 荷姿外形の中心をパレット中心に一致 | X/Y各方向の中心座標誤差 0.01 mm以内 |
| **最大積載高さ (Max Height)** | **1200 mm** | パレット上面からの総積載高さの上限 |
| **長辺方向の荷姿許容幅** | **800 mm 以上 1360 mm 未満** | パレット長辺 (1200mm) 方向のオーバーハング許容。安定性確保のため最小 800mm 以上 |
| **短辺方向の荷姿許容幅** | **800 mm 以上 1100 mm 未満** | パレット短辺 (1000mm) 方向の許容スパン。安定性確保のため最小 800mm 以上 |
| **箱間クリアランス** | **0 mm** | 箱同士は密着させて配置 |
| **小辺のパレット端はみ出し** | **30 mm 未満** | 最下段箱の回転後の底面寸法のうち、335 mm 以下の辺に対応する方向のみ適用。蓋を含む外形で判定 |

---

## 2. 箱の配置・回転制約

1. **天地（上下）固定**
   - 箱の上下反転、横倒し配置は禁止。常に上面が上を向くように配置する。
2. **回転角度**
   - 水平方向（Z軸回り）の回転は **0度** または **90度** のみ許可。
3. **最下段箱の小辺はみ出し**
  - 最下段の各箱について、回転後の底面幅が335 mm以下の場合はX方向、奥行きが335 mm以下の場合はY方向のパレット端からのはみ出しを判定する。
  - 対象方向の片側ごとのはみ出し距離が30 mm以上の場合は禁止する。30 mm未満は許容する。
  - 判定外形には外嵌め蓋が箱本体より外側に出る部分も含める。上段箱には適用しない。
  - はみ出し上限はパレット設定 `max_small_edge_overhang_mm` で変更でき、既定値は30 mmとする。

---

## 3. 嵌合（かんごう）・段積みルール

空箱の上下段積みおよび混載時の嵌合ルールは以下の通りとする。

### (1) TP規格箱の段積み・嵌合
- **モジュール嵌合**:
  - TP規格箱は底面リブ・フチ形状がモジュール化されており、同一型番はもちろん、モジュール倍数関係にある箱（例: TP-330系 2個の上に TP-460系 1個、またはその逆など）の嵌合段積みが可能。
  - TP規格箱同士の組み合わせ段積みルールに準拠すること。
- **外嵌め蓋付きTP箱**:
  - 選択した蓋の `fit_type` が `外嵌め` のTP箱は、積み方の判定上、非TP箱と同じコラム積み限定として扱う。箱DB上の規格種別は変更しない。
  - 上下段は同一の蓋IDを使用し、箱・蓋を含む外形矩形のX/Y位置および範囲を一致させる。箱IDは異なってもよい（例: 同じ外嵌め蓋を使うTP-331とTP-332）。
  - TPモジュール嵌合による異なる外形・位置の段積み、および外嵌め蓋付きTP箱とそれ以外の箱との段積みは禁止する。
- **嵌合高さの計算**:
  - `fitting_depth` は、積み重ねる上段箱（これから配置する箱）の値を使う。
  - 上段箱の底面Z座標 = `下段箱の上面Z座標 - 上段箱のfitting_depth`

### (2) 非TP規格箱（その他箱）の段積み
- **コラム積み（同一フットプリント）限定**:
  - 非TP規格箱は、同一型番（同一フットプリント寸法）の箱同士のみ直上に積み重ね可能。箱・蓋を含む外形矩形のX/Y位置および範囲を一致させ、単一の箱で支持する。
  - 異なる寸法の箱の上に乗せること、または異なる箱を下に乗せることは禁止。

### (3) 支持・安定性制約
- **空中配置の禁止**:
  - すべての箱は、底面が「パレット上面」または「適切な下段の箱の上面」によって確実に支持されていなければならない。
- **リブ干渉の回避**:
  - リブ厚み（`rib_thickness`）による干渉・浮き上がりが生じない配置とすること。
- **下段支持箱のサイズ制限**:
  - 上段箱を直接支持する下段箱について、上段箱より幅・奥行きの両方がそれぞれ 1.0 mm を超えて大きい場合、その段積みは禁止する。
  - 幅・奥行きの一方のみが 1.0 mm を超えて大きい場合、または両方とも同等（差が 1.0 mm 以内）の場合は許可する。

---

## 4. 積載順序（積み込み手順）の制約

- **下段優先・物理的整合性**:
  - 積み込み順序 `order`（1, 2, 3, ...）は、実際にロボットや作業者が配置可能な順序であること。
  - 原則として下段の箱が配置された後に、その上段の箱が配置されること。
  - 後から配置する箱が、既に配置された箱と空間的に干渉・衝突しない順序であること。

---

## 5. 荷姿安定性・最高層四隅高さ一致制約 (Top 4-Corner Leveling)

- **最高層の四隅高さのフラット化**:
  - ストレッチフィルム包装やバンド掛け、多段パレット積み時の安定性を確保するため、荷山全体の**最高層（最上面）において、荷姿の四隅（4つのコーナー）に位置する箱の上面高さ（Top Z）を一致（均一化）**させること。
  - 箱の回転後フットプリント全体を囲む平面外接矩形を考え、$X_{min}/X_{max}$ は最小・最大X座標、$Y_{min}/Y_{max}$ は最小・最大Y座標とする。X軸はパレット長辺方向、Y軸は短辺方向。
  - 四隅はこの外接矩形の4頂点:
    1. **X最小・Y最小の角**: $(X_{min}, Y_{min})$
    2. **X最大・Y最小の角**: $(X_{max}, Y_{min})$
    3. **X最小・Y最大の角**: $(X_{min}, Y_{max})$
    4. **X最大・Y最大の角**: $(X_{max}, Y_{max})$
  - これら4つのコーナーをカバーする最上段の箱の上面高さが、荷山の最高到達高さ $Z_{max}$ と同一（各コーナーの誤差 3.0 mm 以内）であること。

## 6. 制約検証（Supervisorチェック項目）一覧

`supervisor` はアルゴリズムの出力結果（`palletize_result`）に対して以下の項目を検証する：

| チェック項目 | 合格基準 (PASS) | NG時の対応 |
| :--- | :--- | :--- |
| **積載高さ** | 全ての箱の最高Z座標 $\le 1200\text{ mm}$ | 超過箱の除外または段数削減 |
| **長辺寸法** | 荷姿全体の長辺方向幅 $800\text{ mm} \le X_{span} < 1360\text{ mm}$ | 長辺寸法不足または超過の是正 |
| **短辺寸法** | $800\text{ mm} \le$ 荷姿全体の短辺方向幅 $< 1100\text{ mm}$ | 短辺はみ出しまたは不足の是正 |
| **最下段小辺はみ出し** | 底面幅または奥行きが335 mm以下の辺に対応する方向で、箱・蓋外形の片側はみ出しが設定値未満 | 最下段の配置位置または回転を修正 |
| **荷姿センタリング** | 箱・蓋外形から求めた荷姿外接矩形の中心がパレット中心と各方向0.01 mm以内で一致 | 配置全体を再センタリングし、はみ出し条件を再確認 |
| **最高層四隅高さ** | 4つのコーナーそれぞれの最上段箱上面が $Z_{max}$ と 3.0 mm 以内で一致すること | 四隅タワーの高さレベリング |
| **重なり・干渉** | 嵌合深さを除き、箱同士の3Dモデルが干渉（貫通）していないこと | 配置座標の修正 |
| **嵌合・段積み整合性** | TP規格モジュール嵌合または同箱コラム積みのルールを満たしていること | 段積み組み合わせの修正 |
| **支持面チェック** | 底面積の85%以上がパレットまたは下段箱に支持されていること（空中浮きなし） | 配置位置・順序の修正 |
| **下段支持箱サイズ制限** | 直接支持する下段箱が幅・奥行きの両方で上段箱より 1.0 mm を超えて大きくないこと | 段積み組み合わせの修正 |
| **回転角** | 回転角が 0度 または 90度 のみであること | 回転角度の是正 |
| **積み順** | 支持関係にある箱について $order_{lower} < order_{upper}$ の整合性を満たすこと | `order` のソート/再計算 |
