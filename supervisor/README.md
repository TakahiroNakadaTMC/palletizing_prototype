## 1. 概要

本ディレクトリは、[荷姿制約](../constraints/constraints.md) に基づき、
パレタイズ結果が物理的・幾何学的にすべての制約を満たしているかを客観的・機械的にバリデーションし、
検証レポートを発行するスーパーバイザー機能を管理します。

---

## 2. モジュール構成

```text
supervisor/
├── validate.py      # 独立制約バリデーションスクリプト
├── reports/         # 総合検証レポート出力先 (validation_report.md)
└── README.md        # 本ドキュメント
```

## 3. 検証項目（バリデーション基準）

結果JSONの `coordinate_reference` が `combined_footprint_min_xy_top_z` の場合、検証前にXYを箱本体基準へ復元し、上面Zから底面Zを求めます。フィールドのない既存結果は従来の底面基準として扱います。

1. **最大積載高さ制約** ($\le 1200\text{ mm}$)
2. **長辺荷姿スパン制約** ($800\text{ mm} \le X < 1360\text{ mm}$)
3. **短辺荷姿スパン制約** ($800\text{ mm} \le Y < 1100\text{ mm}$)
4. **最高層四隅高さ一致** (各コーナーの誤差 3.0mm 以内)
5. **天地固定・回転角度制約** (0° / 90° のみ、上下反転・横倒し禁止)
6. **嵌合沈み込み計算** ($Z_{upper} = Z_{lower} + H_{lower} - fitting\_depth$)
7. **空中配置禁止・底面支持率** ($\ge 85\%$)
8. **下段箱サイズ超過禁止**（直接支持する下段箱の幅・奥行きが、上段箱より両方とも1.0mmを超えて大きい段積みを禁止）
9. **3D幾何衝突・空間干渉の完全排除** (不正な食い込み 0 件)
10. **積み込み順序（Order）のトポロジカル整合性** ($order_{lower} < order_{upper}$)
11. **オーバーハング制約**（全段の箱・蓋結合外形を対象に、
    X方向は `pallet.max_overhang_x_mm`、Y方向は `pallet.max_overhang_y_mm` の上限値以内。
    既定値は各20mm、20mm自体は許容（inclusive）。）
    - **例外**: INPUT（`input_box_variants`）が単一の荷姿種別（同一 `box_id` + `lid_id`）のみで構成されている場合に限り、その種別と一致する箱について、回転後の箱本体寸法（蓋を含まない）が670mm以上となる軸のみ、当該軸のオーバーハング上限チェックを免除する。ただし長辺・短辺の全体スパン制約（項目2・3）は例外時も変わらず適用される。
    - `input_box_variants` が存在しない旧形式の結果では、配置済み箱から推測せず、常に例外を適用しない（安全側）。
    - 旧キー `pallet.max_small_edge_overhang_mm` が指定されている場合は廃止キーとして違反報告する（既定値へのフォールバックは行うが、設定自体はエラー扱い）。
    - `max_overhang_x_mm` / `max_overhang_y_mm` は0以上の有限数値である必要があり、それ以外の値は違反報告の上、既定値20mmにフォールバックする。
12. **荷姿センタリング**（箱・蓋外形の外接矩形中心とパレット中心が各方向0.01 mm以内で一致）

## 4. 実行方法

```bash
python3 supervisor/validate.py
```

実行すると、ターミナルに各ケースの合否サマリーが表示され、
[検証レポート](reports/validation_report.md) に詳細レポートが出力されます。
