# アルゴリズム説明

本ページでは、パレタイズアルゴリズムの技術的な詳細を説明します。

## アルゴリズムの概要

パレタイズアルゴリズムは、以下の制約条件下で箱をパレットに効率的に配置することを目標としています：

- **嵌合制約**: 上下の箱が勘合する深さを考慮
- **リブ制約**: 箱の外周リブが干渉しないように配置
- **はみ出し制限**: 箱がパレット内に収まること
- **耐久性制約**: 段積みパターンに基づく荷重制限

## 嵌合・リブ構造の処理方法

### 嵌合深さ (Fitting Depth)

上下に積み重ねた箱は、勘合により一定深さ（`fitting_depth`）まではまり込みます。

**例**:
- 箱1の高さ: 300mm
- 嵌合深さ: 50mm
- 箱2の実効的な積み上がり高さ: 300 - 50 = 250mm

### リブ厚み (Rib Thickness)

箱の外周にはリブが施されており、隣接箱との干渉を避けるための考慮が必要です。

**配置時の判定**:
- 隣接する箱の距離 >= `rib_thickness1 + rib_thickness2` であることを確認

## 制約条件の実装方法

### 1. 配置可能判定

新たに配置する箱の候補位置について、以下をチェック：

```
- パレット内に収まるか（はみ出し判定）
- 既存の箱と干渉しないか（リブ干渉判定）
- 嵌合可能な下層が存在するか（嵌合整合性判定）
```

### 2. 段積みルール

```
制約ファイル (constraints/constraints.md) から段積みパターンを読み込み
許可される段数、許可される箱の組み合わせを検証
```

### 3. 積み順決定

```
優先度付きルールに基づき、最適な積み順を決定
（例: 重い箱を下層に配置、軽い箱を上層に配置）
```

## アルゴリズムの流れ

```
1. 入力：箱リスト、パレット仕様、制約条件
2. 初期化：パレット上の配置を空で初期化
3. 入力箱のソート（優先度順）
4. 各箱について：
   - 配置可能な位置を探索
   - 制約条件を満たす位置を選定
   - 配置確定
5. 出力：配置座標、回転、積み順の結果
```

## パフォーマンス最適化

### 配置探索の高速化

- **ビン充填アルゴリズム**: First Fit Decreasing (FFD) の応用
- **候補位置の絞り込み**: グリッドベースの分割で探索空間を削減

### メモリ効率

- 占有率の高い配置を優先的に探索
- 不可能な状態を早期に削除
